# EMTI LLT-1 Simulations

Five Python simulations for 21ECC205T Electromagnetic Theory & Interference (SRM IST).

| Script | Topic |
| --- | --- |
| `sim1_gauss_flux.py` | Gauss's law: numerical flux through spherical surfaces |
| `sim2_displacement_current.py` | Displacement current in a parallel-plate capacitor |
| `sim3_lossy_tline.py` | Attenuation and phase on a lossy transmission line |
| `sim4_quarter_wave.py` | Quarter-wave transformer matching 100 Ω to 50 Ω |
| `sim5_smith_chart.py` | Smith chart analysis of a 75 + j25 Ω load |

Requirements: Python 3, NumPy, Matplotlib.

```
pip install numpy matplotlib
python sim1_gauss_flux.py
```

Each script prints its results and saves the matching `.png` plot in the current folder.
